HOW TO PROCEED - IMMEDIATE NEXT STEPS
================================================================================

STEP 1: Install Python 3.11 (30 minutes)
----------------------------------------
1. Go to: https://www.python.org/downloads/
2. Download Python 3.11.x (NOT 3.12 or newer)
3. Run installer
4. Check "Add Python 3.11 to PATH"
5. Verify: py -3.11 --version

STEP 2: Complete Python Setup (15 minutes)
-------------------------------------------
Open CMD in project root:

cd c:\ISL_MudraVaani--main\apps\ml-service
py -3.11 -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
cd ..\..

STEP 3: Generate Synthetic Data (2 minutes)
--------------------------------------------
cd ml\dataset_tool
..\..\apps\ml-service\.venv\Scripts\python.exe download_isl_dataset.py --dataset synthetic --samples 40
cd ..\..

STEP 4: Copy or Train Model (5 minutes)
----------------------------------------
Option A - Copy existing:
mkdir ml\models_out
copy apps\ml\models_out\isl_model.pt ml\models_out\isl_model.pt

Option B - Train new (3-5 minutes):
cd ml\training
..\..\apps\ml-service\.venv\Scripts\python.exe train.py --epochs 40
cd ..\..

STEP 5: Setup Environment (2 minutes)
--------------------------------------
copy apps\server\.env.example apps\server\.env
copy apps\web\.env.example apps\web\.env

Edit apps\server\.env and set JWT_SECRET to any random string

STEP 6: Start PostgreSQL (1 minute)
------------------------------------
docker compose up -d
timeout /t 10
cd apps\server
npm run db:migrate
cd ..\..

STEP 7: Run the Application (3 terminals)
------------------------------------------
Terminal 1:
cd apps\ml-service
.venv\Scripts\activate
uvicorn app.main:app --reload --port 8000

Terminal 2:
cd apps\server
npm run dev

Terminal 3:
cd apps\web
npm run dev

Open browser: http://localhost:5173

TOTAL TIME: ~1 hour (mostly waiting for installations)
