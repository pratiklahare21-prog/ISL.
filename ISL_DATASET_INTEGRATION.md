# ISL Dataset Integration Guide

## Available ISL Datasets

### 1. ISLTranslate Dataset ⭐ RECOMMENDED
**Source:** [Exploration-Lab/ISLTranslate](https://github.com/Exploration-Lab/ISLTranslate)  
**Size:** 31,000 ISL-English sentence/phrase pairs  
**Type:** Continuous sign language videos  
**License:** CC-BY-NC (Non-commercial use)

**Features:**
- Largest ISL translation dataset
- Pre-extracted MediaPipe features available
- Sentence-level translations
- Quality validated by certified ISL signers

**How to Access:**
1. Visit: https://github.com/Exploration-Lab/ISLTranslate
2. Fill download form (linked in README)
3. Download options:
   - `ISL-videos.tar.gz` - Raw videos
   - `mediapipe_holistic_poses1-13.tar.gz` - Pre-extracted features ⭐
4. Extract to `ml/data/external/isltranslate/`

**Data Format:**
```
ISLTranslate.csv: video_uid, english_translation
mediapipe_holistic_poses/: Pre-extracted landmark features
ISL-videos/: Original sign language videos
```

**Citation:**
```bibtex
@inproceedings{joshi-etal-2023-isltranslate,
    title = "{ISLT}ranslate: Dataset for Translating {I}ndian {S}ign {L}anguage",
    author = "Joshi, Abhinav and Agrawal, Susmit and Modi, Ashutosh",
    booktitle = "Findings of ACL 2023",
    year = "2023"
}
```

### 2. ISL-CSLTR Dataset
**Source:** [Mendeley Data](https://data.mendeley.com/datasets/kcmpdxky7p/1)  
**Size:** 700 videos, 100 sentences, 18,863 frames  
**Type:** Sentence and word-level annotations  
**Signers:** 7 different signers

**Features:**
- Sentence-level fully annotated videos
- Word-level images (1,036 images)
- Multiple signer variants
- Time boundary annotations

**How to Access:**
1. Visit: https://data.mendeley.com/datasets/kcmpdxky7p/1
2. Click "Download" (may require Mendeley account)
3. Extract to `ml/data/external/isl-csltr/`

**Acknowledgments:**
Funded by SERB India (Grant SRG/2019/001338)  
Created with Navajeevan School for the Deaf, Andhra Pradesh & SASTRA University

---

### 3. iSign Benchmark Dataset
**Source:** [Research paper](https://arxiv.org/abs/2407.05404)  
**Size:** 118K+ video-sentence/phrase pairs  
**Type:** Multiple NLP tasks

**Features:**
- Largest overall ISL dataset
- Multiple tasks: Video2Text, Pose2Text, Text2Pose, Word Prediction
- Benchmark baseline models included

**Status:** Check paper for data availability

---

### 4. Synthetic Test Data ⚡ QUICK START
**Source:** Generated by `download_isl_dataset.py`  
**Size:** Configurable (default 40 samples per sign)  
**Type:** Randomized landmark sequences

**Features:**
- ✅ Instant generation (no download)
- ✅ Tests training pipeline
- ⚠️ LOW accuracy (not real signs)
- ⚠️ FOR TESTING ONLY

**How to Generate:**
```bash
cd ml/dataset_tool
python download_isl_dataset.py --dataset synthetic --signs A,B,C,HELLO,YES,NO --samples 40
```

## Integration Steps

### Option 1: Quick Start with Synthetic Data (5 minutes)

**Best for:** Testing the pipeline quickly

```bash
# 1. Generate synthetic data
cd ml\dataset_tool
python download_isl_dataset.py --dataset synthetic --samples 40

# 2. Train model

# 3. Evaluate

python evaluate_model.py
```

**Result:** Working system, but LOW accuracy (synthetic ≠ real signs)

---

### Option 2: Use ISLTranslate Pre-extracted Features (Best)

**Best for:** Production use with real data

```bash
# 1. Download ISLTranslate dataset
# Visit: https://github.com/Exploration-Lab/ISLTranslate
# Download: mediapipe_holistic_poses1-13.tar.gz

# 2. Extract to project
mkdir ml\data\external\isltranslate
# Extract tar.gz files here

# 3. Convert to training format
python ml/dataset_tool/convert_isltranslate.py --input ml/data/external/isltranslate/ --output ml/data/raw/

# 4. Train model
cd ml\training
python train.py --epochs 60 --batch-size 32

# 5. Evaluate
cd ..\evaluation
python evaluate_model.py
```

**Result:** High-quality model with real ISL data

---

### Option 3: Record Your Own Data (Most Accurate)

**Best for:** User-specific accuracy

```bash

cd ml\dataset_tool
python collect.py --label A --samples 40
python collect.py --label B --samples 40
# ... repeat for all signs

# 2. Check progress
python check_progress.py --min 40

# 3. Train model
cd ..\training
python train.py --epochs 60

# 4. Evaluate
cd ..\evaluation
python evaluate_model.py
```

**Result:** Best accuracy for your signing style
